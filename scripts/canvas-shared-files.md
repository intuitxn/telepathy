# Shared files

Canonical shared documents for Intuitxn, mirrored here from the telepathy repo
(the repo is the source of truth; the relay copies make them reachable from chat).

| File | Purpose | Note |
|---|---|---|
| `PRODUCT.md` | Product contract | `product` |
| `SOP.md` | Team operating model | `sop` |
| `CHANGELOG.md` | Release history | `changelog` |
| `docs/AGENT_MAP.md` | People, agents, runtimes map | `agent-map` |
| `docs/HARNESS_STATE.md` | Harness state + lesson log | `harness-state` |
| `plugins/telepathy-meta-agents/registry.json` | Meta-agent catalog | `meta-agent-registry` |

Update flow: Steward drafts changes to a file and a note refresh; a human approves.
Read a note with `buzz notes get --name <name>`.
