# Team launch message

Om, Kush — we have built the first internal alpha of Telepathy, our shared place for the context that normally gets fragmented across chats, calls, and agent sessions.

Telepathy is for communication between us. Post a decision, update, question, or announcement; say what changed, why it matters, and what you need. Acknowledge important context so the author knows it landed, and resolve questions with a written outcome. The agents, routing, and artifact work stay underneath the product instead of appearing as more teammates to monitor.

When you join:

1. read **Telepathy starts here**;
2. acknowledge it;
3. share what you are working on, what changed recently, and what you need from us;
4. reply to one teammate or close one open question.

This first release is deliberately an internal alpha. The interaction model works, but shared accounts and server persistence are the next production gate. Your Intuitxn GitHub invitations are already pending; after you accept them, we will set repository access explicitly and complete onboarding together.
