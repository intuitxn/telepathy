## 3. GROWTH axes — kept distinct

| Axis | What grows | Fuel | Cost | Governing text |
|---|---|---|---|---|
| **LARGER** (scale) | fan-out width, agent count, graph nodes/edges, `steps`, run-dir count, budget totals | genuinely independent, distinct-file, one-check subtasks | complexity-cost: recorded budget per wave, waves of `cap`, cost-per-run measured; cost grows with fan-out, not with real work if independence is missing | Budget-before-fan-out; `D > cap` → waves of `cap` (`docs/drafts/meta/self-improvement-and-scale.md:80-86`); failure modes claim-collision / merge-explosion / context-loss / cost-runaway / partial-failure (`:88-96`); ~10⁴ is a **budgeted capability, not a default**; no distributed exclusive claims / merge safety / global ordering today (`:98-106`). Default `cap`/wave-size and cost unit = owner decisions (`:154-170` O1–O2). |
| **SMARTER** (learning) | retained findings, merged knowledge (engram entries), better policies (rule lists), better retrieval (graph + anchors) | attributed evidence: source revision, contract, checker output, concrete inputs/results, toolchain identity, measured cost | stabilization cost: each improvement must become a durable check/program, pass independent check + human review, and replay on a frozen set; single-trial gains are not claims | Stabilization = law / test / dispatched op (`docs/drafts/meta/self-improvement-and-scale.md:110-120`); loop with proposer≠checker + human promotion (`:122-131`); frozen-set before/after + retained counterexamples; zero-gain experiments retained as evidence (`:143-152`); targets S1–S6 (`:132-141`). |

**Tradeoff, complexity-cost-vs-fuel:** scale spends budget to run more of what is already known-independent; learning spends review + frozen-set measurement to convert an instability into a check that makes future scale cheaper. Fanning out a non-independent task buys cost without fuel (`docs/drafts/meta/self-improvement-and-scale.md:98-106`). Merging unreviewed learned content buys knowledge without provenance and must quarantine (`docs/drafts/meta/crdt-merge-proposal.md:52-65`). Both axes draw from the same recorded budget; neither borrows another row's budget silently (`docs/drafts/meta/self-improvement-and-scale.md:61-68`).

## 4. REGULARIZATION rules for recursion — each states the failure it prevents

Failure vocabulary: **divergence** (unbounded recursion/depth), **explosion** (unbounded width/work/cost), **silent drift** (unlogged change presented as converged), **self-acceptance** (agent accepts/resolves/publishes its own work).

| # | Rule | Statement (today's constant / site) | Prevents |
|---|---|---|---|
| R1 | Depth caps | `depth ≥ max_depth() (=3n)` → leaf, no split (`runtime/mundus.bend:631-638,655-658`; law `plan_depth_limit_leaf` at `docs/drafts/meta/mundus-kernel-laws.md:136-152`); every split child depth strictly greater (`plan_termination`) | **Divergence.** Without it, `plan` hosting its own loop recurses forever on a funded task. |
| R2 | Budget conservation with strict decrease | `sum(child budgets) ≤ parent budget` (`plan_budget_conservation`); current split funds one worker with full remaining, scout `0n` (`runtime/mundus.bend:680-682`); recorded before fan-out, per-wave budgets (`docs/drafts/meta/self-improvement-and-scale.md:80-86`); exhaustion→pause, no silent borrow (`:61-68`) | **Explosion (cost runaway).** Without it, each level multiplies spend. Equal/N-way split and default unit open (`docs/drafts/meta/mundus-kernel-laws.md:270-286` Q4; `docs/drafts/meta/self-improvement-and-scale.md:154-170` O1). |
| R3 | Work bounds with constants | `leaf_budget()=2n`, `fanout()=2n` (`runtime/mundus.bend:631-638`); `budget 0`→leaf, at-threshold splits (`counter_*` at `docs/drafts/meta/mundus-kernel-laws.md:136-152`); `mem_work_bound` ≥20-record fixture (`docs/drafts/meta/memory-source-laws.md:29-36`); `max_minute()=2880n` placeholder (`docs/drafts/meta/buzz-mem-history-laws.md:44-54`); width `cap` + waves (`docs/drafts/meta/self-improvement-and-scale.md:80-86`) | **Explosion (width/work).** Without it, one split or one index/history input can demand unbounded work. `cap`, wave size = owner decisions. |
| R4 | Idempotence | Same inputs→identical outputs: `plan_determinism`, `retrieve_determinism`, `verb_dir` determinism, `fold` order witness (`docs/drafts/meta/mundus-kernel-laws.md:92-162`); same `slug\|digest`→one entry via dedupe (`docs/drafts/meta/memory-source-laws.md:20-28`); same `src`→`Dedupe` (`docs/drafts/meta/buzz-mem-history-laws.md:73-83`) | **Explosion (replay amplification) + silent drift (replay changing state).** Without it, retries and both-orders convergence create new state. |
| R5 | Deny-by-default | Empty policy denies; unknown role/action denies; scope violation denies (`runtime/policy.bend:17-24,337-339,407-434` per grep; `docs/drafts/meta/policy-decision.md:23-25`); first-match-wins, monotonic tail (`runtime/policy.bend:29-30`); review-gated never Allows (`runtime/policy.bend:375-379`) | **Silent drift (unauthorized action treated as allowed) + self-acceptance (exception granted by asking).** Without it, a missing rule is permission. |
| R6 | Quarantine-first | Malformed / duplicate-second / conflicting-body / unknown-kind / insane-minute / src-regression → `Quarantine` (or `Dedupe` for exact-duplicate `src`), never silent merge or coerce (`docs/drafts/meta/memory-source-laws.md:25-27`; `docs/drafts/meta/buzz-mem-history-laws.md:73-83`; `docs/drafts/meta/crdt-merge-proposal.md:52-65`); RED stops its row, no merge (`docs/drafts/meta/op-dispatch-convention.md:142-153`) | **Silent drift.** Without it, concurrent writes resolve as last-writer-wins and malformed input is coerced. Tombstone/structured-merge extensions **unverified**. |
| R7 | Human gates + quarantine of self-acceptance | G1 acceptance (exact revision, author≠reviewer) through G6 job resolution; relay sends need owner signer; retire/spend `review:true`; GREEN≠acceptance (`docs/drafts/meta/crdt-merge-proposal.md:67-78`; `docs/drafts/meta/op-dispatch-convention.md:154-157,193-204`; `docs/drafts/meta/policy-decision.md:18-19`); proposer≠checker (`docs/drafts/meta/self-improvement-and-scale.md:122-131`) | **Self-acceptance.** Without it, a GREEN check, a merge, or a policy exception closes its own job. |

Effects stay in the driver (worktrees, subprocess, file IO, identity, network — `docs/drafts/meta/op-dispatch-convention.md:82-104`); ops/agents mustNot accept/merge/push/publish/send/resolve (`:193-204`).
