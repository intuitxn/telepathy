# telepathy — intuitxn harness gateway

> **Prompt → Preview + Bot + Card.** Buzz is the skin, harness is the truth.

- **Harness**: ledger + reservations + tasks — authoritative
- **Gateway**: Buzz plugin — channels / canvas / @bot
- **Runtime**: prime-agent + codex + opencode — one plugin for all
- **Sync**: socket-level continuous sync — workspaces in opencode
- **Publish**: ssh → mac mini → tailscale → intuitxn.com/telepathy

## Quick start
```bash
@telepathy build "<idea>"  # → Preview URL + Bot + Card
```

## Structure
```
agents/       # Bot definitions (J) — charters
harness/     # ledger, socket, reservations
plugins/     # opencode harness + codex unified plugin
workspaces/  # opencode workspaces
site/        # telepathy.intuitxn.com
```

See `HARNESS.md` for protocol.
